# 📦 合集下载

用于从一个包含多集内容的种子中识别剧集、筛选文件并重命名，适合整季补番。合集按本次提交的种子执行下载，不会自动创建持续轮询的 RSS 订阅。

## 使用条件

- 当前仅支持 qBittorrent，需先配置下载器连接。
- 上传 `.torrent` 文件，当前入口不接受磁力链接。
- 程序与下载器应按[下载设置](/config/download)配置一致的路径映射。

## 操作步骤

1. 打开“添加合集”，搜索并选择 Bangumi 作品，核对作品标题和 TMDB 信息。
2. 设置字幕组、季、集数偏移、下载位置，按需要调整匹配、排除、自定义集数规则和重命名模板。
3. 点击“选择并上传种子”，上传合集的 `.torrent` 文件。
4. 点击“预览”，确认识别出的集数、筛选结果和目标文件名。
5. 点击“开始”，程序向 qBittorrent 添加任务，处理文件选择与重命名后启动下载。

不在最终预览结果中的文件会被设为不下载。开始前应确认所需视频和字幕都已识别；如果集数异常，可先调整[自定义集数规则](/custom-episode)或集数偏移，再预览。

合集使用已配置的 qBittorrent 速度、做种限制和内容布局。相关说明见[qBittorrent 设置](/config/download/qbittorrent)。
