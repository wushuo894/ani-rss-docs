# 📚 批量添加订阅

适用于一次添加多部作品，或为同一部作品选择多个字幕组。入口位于 Mikan、AniBT、AnimeGarden 的选番页面。

## 选择作品与字幕组

1. 在选番页面选择要添加的作品与字幕组，需要时选择对应的匹配规则。
2. 打开“批量添加订阅”，程序会按作品分组，并依次解析订阅信息。
3. 每部作品显示在一个可关闭的标签页中；检查标题、季、主 RSS、备用 RSS 和集数偏移。
4. 确认各标签页中的订阅，完成添加。全部处理完后窗口自动关闭。

同一作品的第一个字幕组作为主 RSS，后续字幕组作为备用 RSS。需要调整优先级时，在确认前修改主 RSS 与备用 RSS 配置。实际使用备用源下载，还需开启[备用 RSS](/config/basic/rss#back-rss)。

## 匹配与偏移

选择字幕组时附带的匹配规则会带入订阅，并使用 `{{字幕组名}}:规则` 限定作用范围，避免某个字幕组的规则影响其他字幕组。

开启[自动剧集偏移](/config/basic/add#自动剧集偏移)后，主 RSS 和每个备用 RSS 分别计算偏移。确认前可手工修改，特别是不同字幕组使用不同集数编号时。

## 失败、取消与重复订阅

- 解析依次进行，某个标签页失败不会阻止后面的作品继续加载；可在失败页点击“重试”。
- 关闭不需要的标签页会移除待添加项，已成功添加的订阅不会因此删除。
- 默认不覆盖重复订阅，检测到重复后再询问是否覆盖，见[重复订阅处理](/add-rss#duplicate-subscriptions)。
- 窗口不会因点击遮罩或按 Esc 关闭，可通过窗口关闭按钮结束操作。
