# Chrome 订阅助手

[ANI-RSS Chrome 订阅助手](https://github.com/wushuo894/ani-rss-chrome-ext) 可以在 AniBT、Mikan 和 AnimeGarden 的番剧页面中识别番剧与字幕组，并将订阅直接添加到自己的 ANI-RSS。

::: info 使用前提

- 已部署并可以通过浏览器访问 ANI-RSS
- Chrome 127 或更高版本
- ANI-RSS 的 `API Key`

:::

## 下载与安装

1. 前往 [ani-rss-chrome-ext Releases](https://github.com/wushuo894/ani-rss-chrome-ext/releases/latest) 下载最新的 `ani-rss-chrome-ext-v<版本号>.zip`
2. 将下载的 ZIP 解压到一个固定目录，不要在安装后删除该目录
3. 在 Chrome 地址栏打开 `chrome://extensions`
4. 开启右上角的“开发者模式”
5. 点击“加载已解压的扩展程序”，选择刚才解压得到的目录
6. 将“ANI-RSS 订阅助手”固定到浏览器工具栏

更新扩展时，下载并解压新版本，然后在扩展管理页面重新加载扩展，并刷新已经打开的番剧页面。

## 连接 ANI-RSS

安装后打开扩展的“选项”，填写 ANI-RSS 服务地址和 `API Key`。

服务地址需要填写 ANI-RSS 首页的完整地址，例如：

- 本机：`http://127.0.0.1:7789/`
- 局域网：`http://192.168.1.10:7789/`
- HTTPS 或反向代理子路径：`https://example.com/ani-rss/`

地址必须包含 `http://` 或 `https://`，不要在结尾添加 `/api`，也不要包含账号密码、查询参数或 `#` 片段。

`API Key` 可以在 ANI-RSS 的“设置 → 登录 → API Key”中获取。填写完成后点击“测试连接”或“保存”，并按 Chrome 的提示允许扩展访问 ANI-RSS 所在的主机。

::: warning 妥善保管 API Key
服务地址和 `API Key` 只保存在本机的扩展存储中，不会同步到浏览器账号。请像保管密码一样保管 `API Key`，不要在截图或公开配置中泄露。
:::

## 添加订阅

1. 打开支持站点中的番剧详情页
2. 点击页面右下角的“订阅到 ANI-RSS”，或点击浏览器工具栏中的扩展图标
3. 选择一个字幕组的 RSS；如果没有找到 RSS，可以点击“加载字幕组”，或手动粘贴对应番剧与字幕组的 RSS 地址
4. 点击“解析 RSS”，等待 ANI-RSS 生成订阅草稿
5. 检查标题、字幕组、季度、剧集偏移和下载开关；需要时可以调整匹配与排除规则
6. 可选点击“预览”，检查下载位置、匹配资源、重命名结果、下载状态与缺失集数
7. 确认无误后点击“添加订阅”

打开扩展、选择 RSS 和解析草稿都不会立即保存订阅，只有点击“添加订阅”后才会写入 ANI-RSS。添加成功后，同一个草稿不能重复提交；需要添加其他 RSS 时请重新解析。

下载目录、重命名、通知等扩展中没有展示的字段，会保留 ANI-RSS 返回的设置。

## 支持的站点

| 站点 | 自动识别域名 | 支持的番剧页面 |
| --- | --- | --- |
| AniBT | `anibt.net` | `/anime/<Bangumi ID>` |
| Mikan | `mikanani.me`、`mikanime.tv`、`mikan.sakiko.de` | `/Home/Bangumi/<Mikan ID>` |
| AnimeGarden | `animes.garden`、`api.animes.garden` | `/subject/<Bangumi ID>` 或限定一个作品的筛选页 |

其他镜像域名暂不支持。如果站点改版，页面按钮和自动识别也可能暂时失效，此时可以尝试通过工具栏图标手动填写 RSS。

## RSS 限制

扩展只接受限定为“一个作品和一个字幕组”的 RSS。以下 RSS 不能用于添加订阅：

- 全部字幕组
- 同时选择多个字幕组
- 全站 RSS
- 用户合集
- 包含多个作品的搜索 RSS

## 常见问题

### 页面中没有订阅按钮

确认当前域名和页面格式属于上方支持列表。扩展安装或重新加载后，需要刷新已经打开的站点页面。也可以点击工具栏中的扩展图标，手动填写 RSS。

### 页面按钮无法打开扩展窗口

确认 Chrome 版本不低于 127，并将扩展固定到工具栏后重试。已经在页面中选择的 RSS 会在下一次打开扩展窗口时读取。

### 没有找到字幕组或 RSS

检查 ANI-RSS 日志，并确认 ANI-RSS 所在设备可以正常访问对应站点。也可以手动粘贴限定单个作品和字幕组的 RSS。

### 认证失败或没有访问权限

检查 `API Key` 和服务地址。使用反向代理时，需要确认代理保留 `api-key` 请求头。若提示没有访问权限，请打开扩展设置，重新保存并允许访问 ANI-RSS 主机。

### 返回非 JSON 或无法连接

确认服务地址没有跳转到登录页，反向代理子路径填写正确，并检查 HTTPS 证书是否有效。扩展不会自动跟随接口重定向。

### 添加订阅时超时

写入请求超时后，先到 ANI-RSS 中检查订阅是否已经添加，再决定是否重试。扩展不会自动重试写入操作。

::: tip
扩展当前用于添加订阅，不包含批量添加和已有订阅管理。订阅结果及重复标题处理规则以 ANI-RSS 服务端设置为准。
:::
