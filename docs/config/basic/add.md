# 添加订阅配置

## 只下载最新集

启用此选项后，系统将仅下载每个订阅源的最新一集内容，避免重复下载已观看的剧集，节省存储空间和带宽。

## 标题添加年份

自动在作品标题后添加年份信息，便于区分不同季度的同名作品。

**示例：** `Re：从零开始的异世界生活 (2016)`

- **默认数据源：** 使用 [Bangumi](https://bgm.tv/) 提供的年份信息
- **TMDB 模式：** 使用 [TMDB](https://www.themoviedb.org/) 的年份数据

## 自动剧集偏移

启用后，添加订阅时会根据 RSS 中识别到的最小集数和所选的 [自动偏移类型](#自动偏移类型)，自动填写集数偏移。主 RSS 和各个备用 RSS 会分别计算偏移。

此选项默认关闭，剧场版订阅不进行自动偏移。修改配置不会重新计算已有订阅的偏移。

## 自动偏移类型

需要开启 **自动剧集偏移** 后生效，默认使用 `AutoOffset`。

| 类型 | 偏移规则 | 适用场景 |
| --- | --- | --- |
| `AutoOffset` | 将 RSS 中的最小整数集数调整为第 `1` 集 | 希望每季从第 `1` 集开始编号 |
| `BgmOffset` | 将 RSS 中的最小整数集数调整为 Bangumi 对应条目的最小正篇集数 | 希望跟随 Bangumi 编号，保留跨季度连续集数 |

### AutoOffset

沿用原有的自动偏移方式，以第 `1` 集为起点。

- **无职转生 第二季：** RSS 从第 `0` 集开始 → 偏移为 `+1`，调整后从第 `1` 集开始。
- **我推的孩子 第二季：** 部分字幕组从第 `12` 集开始 → 偏移为 `-11`，调整后从第 `1` 集开始。

### BgmOffset

根据订阅的 `BgmUrl` 获取 Bangumi 正篇剧集列表，以其中最小的集数编号作为起点。

假设 Bangumi 对应条目的正篇从第 `13` 集开始：

| RSS 最小集数 | 自动填写的偏移 | 调整后的起始集数 |
| --- | --- | --- |
| `1` | `+12` | `13` |
| `13` | `0` | `13` |
| `25` | `-12` | `13` |

当 Bangumi 的最小正篇集数大于 `1` 时，订阅的 **季** 会自动设为 `1`，配合连续集数编号使用。如果返回的正篇列表为空，则以第 `1` 集为起点计算偏移。

::: tip 特殊情况
两种类型下，RSS 没有可用条目时偏移均为 `0`。若 RSS 最小集数为 `.5` 集，会将其对齐到目标正篇起始集数的前半集：

- `AutoOffset`：目标正篇从 `1` 开始，`12.5` 偏移 `-12` 后得到 `0.5`。
- `BgmOffset`：假设 Bangumi 正篇从 `13` 开始，`12.5` 的偏移为 `0`；`0.5` 的偏移为 `+12`，两者均得到 `12.5`，后续正篇从 `13` 开始。
:::

::: warning 使用前提
`BgmOffset` 依赖正确的 `BgmUrl` 和可访问的 Bangumi API。自动偏移以 RSS 当前返回的最小集数为依据；如果订阅源已移除早期剧集，计算结果可能不符合预期，可在添加订阅时手动调整集数偏移和季。
:::

## Bangumi 日语标题

添加订阅时自动获取 [Bangumi](https://bgm.tv/) 中的日语原版标题，便于准确识别作品和避免翻译差异。

## TMDB ID

自动获取并嵌入 TMDB 数据库中的作品 ID，用于精确匹配和元数据管理。

**示例：** `女仆冥土小姐。 [tmdbid=242143]`

## TMDB 标题

添加订阅时自动查询并使用 [TMDB](https://www.themoviedb.org/) 数据库中的标准标题，确保标题的一致性和准确性。

## TMDB 语言

根据指定地区获取对应的本地化标题，支持多语言环境下的标题显示。

## 自动刮削

订阅内容更新时自动从 TMDB 获取并更新元数据信息，包括海报、简介、演员信息等，丰富媒体库内容。

## 开启全局排除

默认启用全局排除规则，自动过滤不符合条件的下载内容，提高下载质量。

## 导入全局排除

默认导入预设的全局排除规则，提供开箱即用的内容过滤功能，减少手动配置工作。
