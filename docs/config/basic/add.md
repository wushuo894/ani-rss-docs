# ➕ 添加订阅配置

## 只下载最新集 {#download-new}

启用此选项后，新增订阅默认开启“只下载最新集”。存在发布时间时，与最新条目同一天发布的多集也允许下载，避免漏掉字幕组同日发布的多集内容；无法比较发布时间时，仅保留最新条目。

该设置是新增订阅的默认值，已有订阅需在编辑页面单独调整。它不表示只下载“尚未观看”的剧集。

## 标题添加年份

自动在作品标题后添加年份信息，便于区分不同季度的同名作品。

**示例：** `Re：从零开始的异世界生活 (2016)`

- **默认数据源：** 使用 [Bangumi](https://bgm.tv/) 提供的年份信息
- **TMDB 模式：** 使用 [TMDB](https://www.themoviedb.org/) 的年份数据

## 自动剧集偏移

启用后，添加订阅时会根据 RSS 中识别到的最小集数和所选的 [自动偏移类型](#自动偏移类型)，自动填写集数偏移。主 RSS 和各个备用
RSS 会分别计算偏移。

此选项默认关闭，剧场版订阅不进行自动偏移。修改配置不会重新计算已有订阅的偏移。

## 自动偏移类型

需要开启 **自动剧集偏移** 后生效，默认使用 `Auto`。

| 类型      | 偏移规则                                                     | 适用场景                                  |
|-----------|--------------------------------------------------------------|-------------------------------------------|
| `Auto`    | 将 RSS 中的最小整数集数调整为第 `1` 集                       | 希望每季从第 `1` 集开始编号               |
| `Bangumi` | 将 RSS 中的最小整数集数调整为 Bangumi 对应条目的最小正篇集数 | 希望跟随 Bangumi 编号，保留跨季度连续集数 |

### Auto

沿用原有的自动偏移方式，以第 `1` 集为起点。

- **无职转生 第二季：** RSS 从第 `0` 集开始 → 偏移为 `+1`，调整后从第 `1` 集开始。
- **我推的孩子 第二季：** 部分字幕组从第 `12` 集开始 → 偏移为 `-11`，调整后从第 `1` 集开始。

### Bangumi

根据订阅的 `BgmUrl` 获取 Bangumi 正篇剧集列表，以其中最小的集数编号作为起点。

假设 Bangumi 对应条目的正篇从第 `13` 集开始：

| RSS 最小集数 | 自动填写的偏移 | 调整后的起始集数 |
|--------------|----------------|------------------|
| `1`          | `+12`          | `13`             |
| `13`         | `0`            | `13`             |
| `25`         | `-12`          | `13`             |

当 Bangumi 的最小正篇集数大于 `1` 时，订阅的 **季** 会自动设为 `1`，配合连续集数编号使用。如果返回的正篇列表为空，则以第 `1`
集为起点计算偏移。

::: tip 💡 特殊情况
两种类型下，RSS 没有可用条目时偏移均为 `0`。若 RSS 最小集数为 `.5` 集，会将其对齐到目标正篇起始集数的前半集：

- `Auto`：目标正篇从 `1` 开始，`12.5` 偏移 `-12` 后得到 `0.5`。
- `Bangumi`：假设 Bangumi 正篇从 `13` 开始，`12.5` 的偏移为 `0`；`0.5` 的偏移为 `+12`，两者均得到 `12.5`，后续正篇从 `13`
  开始。
  :::

::: warning ⚠️ 使用前提
`Bangumi` 依赖正确的 `BgmUrl` 和可访问的 Bangumi API。自动偏移以 RSS
当前返回的最小集数为依据；如果订阅源已移除早期剧集，计算结果可能不符合预期，可在添加订阅时手动调整集数偏移和季。
:::

## Bangumi 日语标题

添加订阅时自动获取 [Bangumi](https://bgm.tv/) 中的日语原版标题，便于准确识别作品和避免翻译差异。

## TMDB ID

自动获取并嵌入 TMDB 数据库中的作品 ID，用于精确匹配和元数据管理。

**示例：** `女仆冥土小姐。 [tmdbid=242143]`

启用 **Plex Mode** 后，标题中的 TMDB ID 使用适合 Plex 的 `{tmdb-242143}` 格式。

## TMDB 标题

添加订阅时自动查询并使用 [TMDB](https://www.themoviedb.org/) 数据库中的标准标题，确保标题的一致性和准确性。

附加选项包括：

- **仅获取动漫：** 限制 TMDB 查询的作品范围。
- **使用原标题：** 使用 TMDB 的原始标题。
- **优先获取罗马音：** 优先尝试获取罗马音标题，具体结果取决于数据源。

## TMDB 语言

根据指定地区获取对应的本地化标题，支持多语言环境下的标题显示。

## 自动刮削

此选项位于“设置 → 基本设置 → 刮削设置”，用于在下载完成时刮削本地媒体。追更天数、`tvshow.nfo`、`bangumi.ini` 与 TMDB
接口配置请查看[刮削设置](/config/basic/scrape)。

## 开启全局排除

默认启用全局排除规则，自动过滤不符合条件的下载内容，提高下载质量。

## 导入全局排除

默认导入预设的全局排除规则，提供开箱即用的内容过滤功能，减少手动配置工作。

“开启全局排除”让新订阅使用全局规则；“导入全局排除”将当前全局规则复制到新订阅的排除列表，之后可单独修改。界面中两者互斥，按需要选择一种方式。

## 封面质量

设置获取 Bangumi 封面的质量，可选择 `large`、`medium`、`common`，用于权衡图片清晰度与加载速度。

## 默认自定义集数规则

为新订阅预设自定义集数规则开关、正则表达式和捕获组索引。具体写法见[自定义集数匹配规则](/custom-episode)。

## 自动上传

设置新增订阅的“自动上传”默认值。实际上传仍需配置[OpenList 上传通知](/config/notification#openlist-upload)
，不会仅凭此开关创建上传连接或上传任务。
