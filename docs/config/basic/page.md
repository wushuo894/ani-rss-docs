# 🎨 页面设置

### 按星期展示

按星期展示，优先显示当前星期。

适合追更场景：开启后，番剧列表会更偏向按一周播出节奏来查看，今天所在的星期通常会被优先展示，方便快速查看今日更新。

### 显示评分

显示 [Bangumi](https://bgm.tv/) 评分。

适合在选番、补番时快速参考作品热度和口碑。如果某个条目尚未同步到 Bangumi，或 Bangumi 暂无评分，则该位置可能不会显示内容。

### 外观与主题色

外观支持自动、浅色和深色模式，可使用主题色选择器调整界面主色。

### 排序

订阅支持按 Bangumi 评分、拼音或更新时间排序。

### 点击封面 {#cover-click}

可选择“编辑订阅”“视频列表”或“编辑封面”，默认是“编辑订阅”。也可以通过封面菜单打开视频列表，无需开启额外的“显示视频列表”开关。

视频列表与内置、外部播放器的用法见[视频播放](/play)。

### 启动页

设置打开界面后默认进入首页或订阅页。

### 最大内容宽度

设置页面内容区域的最大宽度，单位为像素，最小为 `1200`。

### 显示更新时间

在订阅卡片上显示最近下载更新时间。

::: tip 💾 保存范围
外观、主题色、按星期展示、显示评分、点击封面、启动页、最大内容宽度和显示更新时间保存在当前浏览器中；排序、自定义 CSS / JavaScript 等配置随服务端设置保存。更换浏览器不会自动同步本地显示偏好。
:::

### 自定义 CSS

用于自定义网页界面的样式，例如：

- 调整卡片布局、字号、间距
- 隐藏不常用按钮
- 自定义亮色/暗色主题效果

你可以前往 <https://github.com/wushuo894/ani-rss-css> 或 <https://zzzwannasleep.github.io/ani-rss-themes> 复制现成的
`CSS` 模板后再按需修改。

::: tip 💡 使用建议
自定义 CSS 只会影响页面显示效果，不会影响订阅、下载、重命名等实际功能逻辑。
:::

### 自定义 JavaScript

在“自定义 → JavaScript”中填写需要在页面加载时执行的脚本，用于扩展界面交互。自定义脚本与 CSS 一样是页面定制入口；它不会自动修改后台的下载设置。

### WebUI { #webui }

可上传第三方 WebUI，将覆盖内置的默认前端加载。

开发自己的前端请阅读[第三方 WebUI 制作标准与指南](/dev/webui)，包含 ZIP 包结构、`webui.json`、鉴权、`api/webui/*` 接口、更新发布与恢复默认界面的方法。

第三方 WebUI 推荐:

<https://zzzwannasleep.github.io/ani-rss-themes/webui>
