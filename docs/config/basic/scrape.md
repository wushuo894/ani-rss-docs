# 刮削设置

入口：**设置 → 基本设置 → 刮削设置**。刮削用于向本地媒体目录写入 TMDB 元数据和图片，供媒体库识别。

## 自动刮削

开启后，程序处理下载完成时尝试刮削。订阅需要有正确的 TMDB 信息；本地目录必须能被 ANI-RSS 访问。Aria2 不支持这条下载完成处理链路，不能依赖其触发自动刮削。

也可从订阅封面菜单选择“刮削”或“刮削 [F]”。普通刮削主要补全缺失文件；`[F]` 表示强制刷新已有元数据与图片。

## 追更天数

单位为天，用于刷新近期播出剧集的元数据。每次刮削时，TMDB 播出日期位于该天数范围内的剧集，会刷新已有的集 NFO 和缩略图，便于补全尚未完善的标题、简介等信息。

它不是独立的定时刮削间隔。

## tvshow.nfo 与本地文件 {#tvshow-nfo}

电视剧使用默认的“作品目录 / Season 季”结构时，会生成：

- 作品目录：`tvshow.nfo`、作品图片、`seasonXX-poster.*` 季封面。
- 季目录：`season.nfo`、与视频同名的 `.nfo` 和 `-thumb.*` 集缩略图。

`tvshow.nfo` 写在当前下载目录的上一级。如果自定义目录结构，需要据此确认文件位置。

设置 TMDB 剧集组后，刮削使用对应的季、集元数据；请同时核对订阅的季与集数编号。无法匹配到 TMDB 剧集的文件和 `.5` 集不会生成对应的集元数据。

剧场版使用电影元数据，生成视频对应的 NFO 与图片。

## bangumi.ini

开启后，在刮削时将 `bangumi.ini` 写入订阅下载目录，记录 Bangumi 条目 ID 和订阅集数偏移，例如：

```ini
[Bangumi]
id=544109
offset=0
```

普通刮削保留已有文件，强制刮削会重新写入。请确保 `BgmUrl` 与偏移正确。

## TMDB 接口配置

| 设置 | 用途 |
| --- | --- |
| `TmdbApi` | TMDB API 地址，默认 `https://api.themoviedb.org` |
| `TmdbApiKey` | 自备 API 密钥，留空使用系统默认 |
| `TmdbImage` | TMDB 图片服务地址，默认 `https://image.tmdb.org` |

标题选择与语言选项仍位于[添加订阅配置](/config/basic/add)。
