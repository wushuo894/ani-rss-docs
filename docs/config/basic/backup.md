# 💾 备份与恢复

入口：**设置 → 基本设置 → 备份**。

## 自动备份配置

启用后，每天 `00:00` 按程序运行环境的时区备份一次，文件保存到配置目录的 `backup/YYYY-MM-DD.zip`。同一天已有备份时不会重复生成。

右侧的“天”表示备份保留天数，不是每隔多少天执行。程序在自动备份时清理过期备份；关闭开关后不再执行自动备份。

## 导出设置

点击“导出设置”下载 ZIP 备份，包含设置、订阅数据、相关 `files` 数据和 `torrents` 种子记录，不包含下载的视频。迁移媒体时，需要另外迁移视频目录，并配置新环境的下载器地址与路径。

## 导入设置

1. 如需保留当前状态，先导出当前设置。
2. 点击“导入设置”，确认覆盖提示后选择之前导出的 ZIP。
3. 导入成功后，程序重新加载设置、订阅并重启后台任务，页面会刷新。

导入会覆盖备份中的设置和订阅，并替换现有种子下载记录；它不是把订阅合并进现有列表。导入后使用备份中的账号密码和 API Key。

仅需要合并订阅时，应使用订阅列表中的 JSON 导入功能，按界面选择“替换现有数据”或“跳过冲突数据”，不要使用完整备份导入。
