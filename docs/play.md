# ▶️ 视频播放

## 打开视频列表

从订阅封面菜单选择“视频列表”，也可将[点击封面](/config/basic/page#cover-click)设置为“视频列表”，再点击封面打开。

列表读取该订阅下载目录中的本地视频文件。若没有内容，请确认文件已下载、ANI-RSS 可以访问对应目录，且 Docker 中的路径映射与下载器一致。小于 `20 MiB` 的视频文件不会出现在列表中。

## 内置播放器

点击列表中的播放按钮打开内置 Movi 播放器，通过 WASM 播放媒体。能否流畅播放取决于视频编码、客户端性能和网络；列表中出现文件并不代表所有客户端都能顺畅解码。

## 外部播放器

播放器右下方的“更多”菜单可调用 PotPlayer、VLC、IINA、MPV、Infuse、弹弹Play、AnimacX 和 SenPlayer。

使用前需在当前设备安装相应播放器，并让浏览器可以打开其协议链接。VLC 和 MPV 的协议注册方式见[播放器常见问题](/faq#player)。外部播放器所在设备也需要能访问 ANI-RSS 提供的视频地址。
